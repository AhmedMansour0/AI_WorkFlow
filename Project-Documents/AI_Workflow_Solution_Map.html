QA Workflow Solution Map

Five milestones, each driven by a reusable skill and governed by CLAUDE.md. Each milestone writes one deliverable to disk, and later milestones read it back as input.

  1. 1 · PRDScan the live UI and API and write requirements with stable IDs.
  2. 2 · ExploreCheck the PRD against the real build; capture locators, API payloads and deviations.
  3. 3 · Test casesTurn requirements and findings into CSV test cases, flagged for scope and automation.
  4. 4 · ExecuteMark each case pass or fail and publish the HTML report and the bug reports.
  5. 5 · AutomateBuild the Playwright suite, run it, and self-heal test failures.
